Quick Actions

SET — Add / Update Cache Entry

Store a value in the cache with an optional TTL (time-to-live).

Allowed: letters, numbers, : . - _ * ?
Logical grouping for key organisation.
Accepts plain text or valid JSON. Input is XSS-sanitised before storage.
Leave TTL blank for a persistent (non-expiring) key.

Flush Cache

Permanently delete all keys from the cache. This action cannot be undone.

⚠️

Danger Zone — Irreversible Action

Flushing the cache will remove all cached property listings, session tokens, configuration values, and analytics data stored in this browser. Staff will experience increased load times until the cache is repopulated.
